An IoT monitoring concept for drainage infrastructure and potential sewer blockages.

DrainWatch explores how connected sensor nodes and real-time dashboards can help monitor underground drainage conditions and identify potential problems.

Project areas:

- Sensor-based telemetry from embedded nodes.
- Geographic visualization using MapLibre.
- React and Tailwind CSS monitoring dashboard.
- FastAPI backend and WebSocket-based updates.
- MQTT-based telemetry and simulated sensor data.
- ESP32-based nodes and wireless communication.

Technology focus: React, Tailwind CSS, FastAPI, SQLite, WebSockets, MQTT, ESP32 and LoRa.

03. Edge AI Voice Assistant — Exploration

Exploring a local voice-assistant pipeline for resource-constrained hardware.

This concept focuses on bringing speech processing and AI capabilities closer to the device rather than relying on a powerful cloud-connected machine for every operation.

Areas of exploration:

- Local speech recognition using Whisper.cpp.
- LLM integration for conversational responses.
- Text-to-speech using Piper.
- Raspberry Pi deployment and resource management.
- Balancing memory usage, inference latency, and usability.

Technology focus: Raspberry Pi, Linux, speech processing, LLMs and edge AI.

An exploratory project concept; individual components and deployment choices depend on testing.

---

04. Lightweight Keyword Spotting for Edge Devices

Exploring low-latency voice activation for embedded systems.

The objective is to recognize a specific wake word locally on a low-power device and trigger further speech processing only when needed.

Areas of exploration:

- I2S microphone audio acquisition.
- Custom audio dataset preparation.
- Lightweight classification and keyword detection.
- Accuracy, inference latency, and memory-footprint evaluation.
- ESP32-S3 and other resource-constrained hardware.

Technology focus: Python, audio processing, machine learning, ESP32-S3 and TinyML.

An area of experimentation focused on efficient on-device inference.
